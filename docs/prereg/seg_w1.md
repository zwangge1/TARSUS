## 0. 符号

| 符号 | 含义 |
|---|---|
| A、B、C、D | 实验组。A：官方 DLC，SA 初始化，只用人工标注。B：A + 全鸟统一先验 loss。C：A + 按物种条件化先验 loss。D：C + 经先验过滤的伪标签帧 |
| knee、hip | Duong 标注里的 `left/right_knee`、`left/right_hip`，人工估计，非 X 光真值 |
| itj、tmp | Duong 标注里的 `ankle`、`foot` |
| PCK@$\alpha$ | 预测点与人工点的距离小于 $\alpha\times$ 归一化长度的比例 |
| 归一化长度 | 主指标：该帧全部人工标注点外接框的对角线长度。副指标：该帧人工 itj 到 tmp 的长度 |
| CV | 同一段视频内，预测骨长比 $\ell_{tib}/\ell_{tmt}$ 的变异系数（标准差除以均值） |

## 1. 数据与划分

- 数据：`FFY/duong_data/deeplabcut/bird-landing-Duong-2025-06-29/labeled-data/` 下全部 `CollectedData_Duong.csv`（10-30 统计：759 帧，四个物种）。
- 去重：同一视频的不同文件夹（例如 `Duck_1` 与 `Duck_1_final`）按视频编号归为一组，同一组的帧只能整体在训练集或整体在测试集，不能拆开。完全重复的帧只保留一份。
- 划分：物种留一，共 4 折（鸭、鹅、鹈鹕、天鹅轮流做测试）。测试物种的任何帧（包括未标注视频）都不进训练。
- 种子：每组每折至少 2 个种子，各个种子的结果都报，同时报均值。

## 2. 判据（看结果前定死）

1. **伪标签过滤（M6）**：先验过滤后，伪标签的视频内 CV 相对下降 ≥20%；同时可见点（itj、tmp、toe）在人工标注帧上的 RMSE 相对上升不超过 5%。
2. **C 对 A**：knee 的 PCK@0.1（主归一化），4 折平均提高 ≥10 个百分点。
3. **C 对 B**：knee 的 PCK@0.1，4 折平均提高 >0，并且至少 3 折方向一致。

决策规则：1 和 2 都通过，就全力推进。2 不通过，说明先验太松，回到只做先验库。3 不通过，"物种条件化"这个卖点不成立，要在论文里如实说明，并重新考虑论文定位。

## 3. 同时报告、但不作判据的指标

hip 的 PCK@0.05 和 PCK@0.1；副归一化下的 PCK；可见点的 RMSE；组 D 相对 C 的变化；A0（Duong 原模型）作为历史参照。

## 4. 已知局限（写进论文）

knee、hip 的参考答案是人工估计。本预注册只检验"与人工估计的一致性"，不检验"与真实关节位置的一致性"。硬真值验证另立预注册（BROWN20 或 Andrada 数据到手后再写）。
