## 0. 符号

| 符号 | 含义 |
|---|---|
| A、B、C、D | 实验组。A：官方 DLC，SA 初始化，只用人工标注。B：A + 全鸟统一先验 loss。C：A + 按物种条件化先验 loss。D：C + 经先验过滤的伪标签帧 |
| SA | `superanimal_bird`，DLC 官方鸟类预训练模型 |
| knee、hip | Duong 标注里的 `left/right_knee`、`left/right_hip`，人工估计，非 X 光真值 |
| itj、tmp | Duong 标注里的 `ankle`、`foot`，外露可见 |
| PCK@$\alpha$ | 预测点与参考点的距离小于 $\alpha\times$ 归一化长度的比例 |
| 归一化长度 | 主：该帧全部人工标注点外接框的对角线。副：该帧人工 itj 到 tmp 的长度 |
| CV | 同一段视频内，预测骨长比 $\ell_{tib}/\ell_{tmt}$ 的变异系数 |
| 一致性上限 | 两位标注者在同一批帧上互相比的 PCK@0.1，模型不可能稳定超过它 |

## 1. 数据与划分

- 数据：`duong_data/deeplabcut/bird-landing-Duong-2025-06-29/labeled-data/` 下全部 `CollectedData_Duong.csv`（759 帧，四个物种；SA 能检出的 628 帧）。
- 去重：同一视频的不同文件夹（如 `Duck_1` 与 `Duck_1_final`）按视频编号归为一组，整组只能在训练集或测试集一边。完全重复的帧只保留一份。
- 划分：物种留一，4 折（鸭、鹅、鹈鹕、天鹅轮流做测试）。测试物种的任何帧（含未标注视频）都不进训练。
- 种子：每组每折至少 2 个种子，各种子结果都报，同时报均值。
- 初始化（10-30 W1 实测定）：Duong `ankle` 用 SA `tibia` 初始化，`foot` 用 SA `foot`，knee、hip、foot_tip 与 SA 无对应，重新初始化；躯干点按逐个核对后的对应表。

## 2. 参考答案的已知偏差（判据前写明）

10-30 诊断（`prior/proj_diag.json`、W1b）：
- 鹅、天鹅、鹈鹕的人工 hip 到 knee 在 2D 上比骨骼数据短 35% 到 40%；鸭基本一致。来源可能是视角造成的透视缩短，也可能是髋点标偏，2D 无法区分。
- 同一段视频内骨长比的标准差约 0.2（对数尺度），与物种间差异同量级。
- 因此 PCK 衡量的是"与人工估计的接近程度"，不是"与真实关节位置的接近程度"。
- **一致性上限**：抽 50 帧（每物种 12 到 13 帧），由第二位标注者只标 hip、knee、itj、tmp，算两人间 PCK@0.1（按关节、按物种）。模型 PCK 对着这个上限报告。此项若未完成，判据照常执行，但论文中必须注明缺失。

## 3. 判据（看结果前定死）

1. **伪标签过滤（M6）**：先验过滤后，伪标签的视频内 CV 相对下降 ≥20%；可见点（itj、tmp、toe）在人工标注帧上的 RMSE 相对上升不超过 5%。
2. **C 对 A**：knee 的 PCK@0.1（主归一化），4 折平均提高 ≥10 个百分点。
3. **C 对 B**：knee 的 PCK@0.1，4 折平均提高 >0，且至少 3 折方向一致。
4. **护栏**：C 的可见点 RMSE 相对 A 上升不超过 5%。

判定只看 4 折平均，不按物种挑选；鸭单独的数字只作描述。

决策规则：1、2、4 都通过，全力推进。2 不通过，先验太松，回到只做先验库。3 不通过，"物种条件化"卖点不成立，如实写明并重新考虑论文定位。

## 4. 同时报告、但不作判据

hip 的 PCK@0.05、PCK@0.1；鸭单独的 knee、hip PCK；副归一化下的 PCK；可见点 RMSE；视频内 CV（A、B、C、D）；D 相对 C 的变化；A0（Duong 原模型）作历史参照；模型 PCK 与一致性上限的差。

## 5. 本预注册能回答与不能回答的

- 能回答：先验能否让 DLC 的膝髋预测更接近人工估计，且不损害可见点；物种条件化相对全鸟平均有无增量。
- 不能回答：膝髋推得是否正确。这是论文核心结论，由 **seg_gt** 回答（BROWN20 或 Andrada 数据到手后另写，判据届时先于结果定）。
